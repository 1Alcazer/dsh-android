DSH Android — third-party notices

DSH Android is an unofficial shell. It bundles the official DeepSeek Harness
production tree and a pinned Android arm64 runtime built from Termux packages.
This file and the accompanying license texts are shipped inside the APK at
assets/licenses/.

Corresponding source
  The GPL and LGPL binaries are built from the Termux recipes for the exact
  versions above:
  https://github.com/termux/termux-packages/tree/master/packages
  Each recipe points at the upstream source tarball and carries the Termux
  patches used for Android. Upstream sources are available from the project
  URLs in the table.

  The binaries differ from upstream only by mechanical ELF string substitutions
  performed by engine/elf-patch.mjs in the DSH Android source repository:
  Android-safe SONAMEs (for example libz-1.so instead of libz.so.1) and a
  RUNPATH of $ORIGIN. No executable code is altered. The scripts that perform
  these substitutions are part of the corresponding build materials.
